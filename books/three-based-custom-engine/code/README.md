# code/ — рабочее место захода (в репозиторий не попадает)

Здесь во время написания главы живёт рабочий проект движка: тот самый код, который цитируется в главе листингами и на котором сняты все её числа — счётчики `renderer.info`, вывод прогонов, поведение браузера. **Каталог очищается в конце захода, и его содержимое не коммитится** (решение владельца 2026-08-02): код рабочего места — леса для стройки текста, а не артефакт книги. В git отслеживается только этот файл; всё остальное в каталоге закрыто правилом `.gitignore`.

Сейчас каталог пуст: заход по главе 5 закрыт.

## Где хранится код, который имеет смысл хранить

**В снимках контрольных точек — `engine/checkpoint-NN/`.** Это документированные состояния движка (решение 6.3, конвенция 3.2 `outline.md`), они живут в репозитории постоянно и пригодны к запуску: `npm install && npm test`. Снимки снимаются в главах 5, 9, 13, 18 и 22.

**Отсюда же начинается следующий заход.** Проект разворачивается из последнего снимка, а поверх него набираются листинги глав, написанных после снимка. Листинги для этого годятся: сверочный скрипт захода проверяет, что каждый из них — дословный непрерывный фрагмент реального файла.

```
engine/checkpoint-01/   → главы 6, 7, 8   (плюс их листинги)
engine/checkpoint-02/   → главы 10, 11, 12
…
```
