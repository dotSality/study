# code/ — рабочий проект захода (временный по определению)

Здесь во время написания главы живёт рабочий проект движка: тот самый код, который цитируется в главе листингами и на котором сняты все её числа — счётчики `renderer.info`, вывод прогонов, поведение браузера. **После закрытия главы каталог очищается** (решение владельца 2026-07-30): код — леса для стройки текста, а не артефакт книги.

Сейчас каталог пуст: главы 1, 2, 3 и 4 закрыты.

## Как это работает в заходе

1. В начале захода здесь разворачивается проект — точная копия того, что к этому моменту собрал у себя читатель: `package.json` с точными версиями, `tsconfig.json`, `src/`, `tests/`, `harness/`, `web/`.
2. Код пишется и прогоняется **до** текста главы. Правило 5.4: несобирающийся фрагмент в главу не попадает, а каждое число берётся из прогона, а не из головы.
3. Листинги главы сверяются со сверочным скриптом захода: каждый обязан быть дословным непрерывным фрагментом реального файла.
4. Глава закрывается — каталог очищается, остаётся только этот файл.

## Где взять код закрытой главы

Он не потерян: рабочий проект каждой главы попадает в коммит захода. Восстановить любой файл или каталог целиком:

```
git log --oneline -- books/three-based-custom-engine/code
git show <коммит>:books/three-based-custom-engine/code/chapters/02-frame-loop/src/engine/loop.ts
git checkout <коммит> -- books/three-based-custom-engine/code/chapters/02-frame-loop
```

Состояния, зафиксированные на 2026-08-01: глава 1 — коммит `163d732`, глава 2 — `fc623d7`, глава 3 — `290dc18`, глава 4 — `7c32c3f` (во всех путь `code/chapters/NN-<slug>/`, оболочка-переключатель — `code/shell/`). В коммите захода лежит проект целиком, то есть каталоги всех глав до текущей включительно: восстанавливая одну главу, вы получаете и предыдущие.

Одна тонкость приёма: `git checkout <коммит> -- .../code` возвращает вместе с проектом и **этот файл** в его тогдашней редакции. После восстановления верните актуальный: `git checkout HEAD -- books/three-based-custom-engine/code/README.md`.

Второй путь — сама книга: листинги глав проверены дословно, поэтому проект восстанавливается набором из текста, как это делает читатель.
