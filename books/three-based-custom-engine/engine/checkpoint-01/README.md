# checkpoint-01 — минимальное ядро

Первое документированное состояние движка книги «Свой 3D-движок для веб-игр на three.js». Снято после главы 5 (контрольная точка 1). С этого состояния можно войти в книгу заново, не читая глав 1–4: код здесь полный и рабочий, а всё, почему он такой, разобрано в главах.

**Контур, на котором снимок проверен (2026-08-02):** three 0.185.1, TypeScript 7.0.2, esbuild 0.28.1, Playwright 1.62.0, Node.js 24.15.0, Google Chrome 151.0.7922.71.

## Что умеет движок на этой точке

| Подсистема | Файл | Что делает |
|---|---|---|
| Размер картинки | `src/engine/viewport.ts` | CSS-размер и плотность → буфер рисования, потолок плотности |
| Часы | `src/engine/clock.ts` | реальное и игровое время, пауза, масштаб, ручной шаг |
| Фиксированный шаг | `src/engine/fixed-step.ts` | аккумулятор, два потолка, альфа для интерполяции |
| Источник кадров | `src/engine/frame-source.ts` | браузерный (`requestAnimationFrame`) и ручной |
| Планировщик | `src/engine/scheduler.ts` | фазы `input → fixed → update → render`, порядок внутри фазы |
| Цикл | `src/engine/loop.ts` | кадр целиком: часы, шаги, фазы, сброс |
| Пул | `src/engine/pool.ts` | постоянный запас объектов, отказ вместо роста |
| Математика | `src/engine/math.ts` | соглашения, чтение столбцов, точка против направления |
| Повороты | `src/engine/rotation.ts` | кватернионы, порядок углов `YXZ`, интерполяция |
| Граф сцены | `src/engine/scene-graph.ts` | иерархия, грязный флаг, один обход за кадр |
| Камера | `src/engine/camera.ts` | узел графа + матрицы вида и проекции, цепочка пространств |
| Реестр сущностей | `src/engine/entity.ts` | дескриптор «индекс + поколение», устаревшие ссылки |
| Хранилища | `src/engine/component-store.ts`, `src/engine/vector-store.ts` | плотный массив с разрежённой картой; раскладка «структура массивов» |
| Мир | `src/engine/world.ts` | реестр + хранилища, отложенное удаление |
| События | `src/engine/events.ts` | очередь постоянной ёмкости, доставка в будущее, граница партии |
| **Сборка** | `src/engine/engine.ts` | всё перечисленное как один движок: системы ядра, подсистемы, сброс, счётчики |
| **Конфигурация** | `src/engine/config.ts` | один проверяемый объект настроек |
| **Точка входа** | `src/engine/index.ts` | публичная поверхность движка |
| Мост к three.js | `src/render/view.ts` | подсистема **над** ядром: рендерер, сцена, отрисовка камерой движка |

Чего на этой точке ещё нет: конвейера ресурсов (главы 6–9), слоя рендера (главы 10–13), ввода, анимации, физики и звука (главы 14–18), оптимизаций (главы 19–22), спроектированного публичного API (глава 23).

## Проектные решения, действующие в этом состоянии

Блок I, девятнадцать решений глав 1–4 и пять решений главы 5. Полные формулировки — в конце соответствующих частей глав, сводка — в части 5.3.

| Решение | Коротко |
|---|---|
| Р1.1 | потолок плотности пикселей — 2 |
| Р1.2 | свой сервер стенда (нужны COOP/COEP) |
| Р1.3 | только стираемый синтаксис TypeScript |
| Р1.4 | адаптер соответствия между стендом и движком |
| Р2.1 | свой цикл поверх `requestAnimationFrame`, источник кадров подменяем |
| Р2.2 | фиксированный шаг 60 Гц с двумя потолками |
| Р2.3 | интерполяция, а не экстраполяция |
| Р2.4 | часы движка отдельно от цикла и от three.js |
| Р2.5 | пул с постоянной ёмкостью и отказом вместо роста |
| Р3.1 | математика из three, смысл добавляет движок |
| Р3.2 | ориентация кватернионом, порядок углов `YXZ` |
| Р3.3 | мировые матрицы — один обход с грязным флагом |
| Р3.4 | узел не даёт менять себя мимо флага |
| Р3.5 | камера как узел графа, система координат задана явно |
| Р4.1 | сущность — число, а не объект |
| Р4.2 | индекс и поколение упакованы в одно число |
| Р4.3 | плотный массив с разрежённой картой, удаление обменом с последним |
| Р4.4 | система — проход по хранилищу, порядок задаётся явно |
| Р4.5 | очередь событий постоянной ёмкости с границей партии |
| Р5.1 | точка входа — явный список, а не `export *` |
| Р5.2 | конфигурация — один проверяемый объект, отказ вместо умолчания |
| Р5.3 | системы ядра расставляет само ядро и не даёт их снять |
| Р5.4 | эталонный кадр сверяется по пикселям, версия браузера пишется рядом |
| Р5.5 | рендер не входит в ядро: мост к three.js — подсистема над ним |

## Команды прогона

```
npm install          # зависимости из package.json, версии точные
npm run typecheck    # tsc --noEmit: типы и запрет нестираемого синтаксиса
npm test             # оба слоя проверок одной командой
npm run dev          # стенд на http://127.0.0.1:5173/index.html
```

`npm test` запускает 173 теста: 143 достались от глав 1–4 и 30 добавила контрольная точка. Из них три сценария слоя 2 поднимают настоящий Chrome, остальные идут в Node без графики.

Отдельно, вне `npm test`:

```
node --expose-gc harness/hot-loop.mjs 50000    # измерение дисциплины кадра
REFERENCE=refresh node --test harness/checkpoint-01.test.mjs   # переснять эталонный кадр
```

## Критерии приёмки контрольной точки

**Слой 1 (счётчики, одинаковы на любой машине).** Обходов графа за кадр — 1; посещений узлов за 61 кадр — 2135 при 35 узлах; аллокаций в горячем цикле — 0 (проверяется тождеством объектов в `tests/hot-loop.test.mjs`).

**Слой 2 (браузер).** 61 кадр детерминированной сцены совпадает с эталоном `harness/reference/checkpoint-01-core.png` попиксельно; ошибок консоли — 0.

**Слой 3 (Node).** Фиксированный шаг даёт расчётное число шагов на заданное модельное время; после перемещения родителя пересчитаны мировые матрицы всех его потомков и только их; создание и удаление сущностей не нарушает порядок систем. Всё три — `tests/checkpoint.test.mjs`.

Эталонный кадр и его паспорт (версия браузера, версия three, счётчики) лежат в книге: `harness/reference/checkpoint-01-core.png` и `.json`. Сценарий находит их сам, поднимаясь от своего каталога до корня книги.

## Адаптер соответствия

`tests/adapter.mjs` — единственное место, которое знает и имена стенда, и имена вашего движка. Он импортирует ровно один файл, `src/engine/index.ts`; если для проверки понадобилось заглянуть в модуль мимо точки входа, это ловит `tests/surface.test.mjs`. Переименовали что-нибудь в движке — правьте адаптер, тесты не трогайте.
