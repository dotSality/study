# Conventions (книга C→Rust)

> Эта память — только про книгу C→Rust. Правила asm-книги (`books/asm-book/`) живут в `asm-book-requirements.md` (FR-1…FR-7, NFR-1…NFR-5) и в `sources.md` §5; главные отличия — верификация каждой программы **на двух контурах** (L и M) вместо одного эталона, собственное пространство ID заданий и другие арбитры (psABI, AMD64 APM, POSIX, ECMA-48, GNU as). Указатель: `mem:asm-book-progress`.

Нормативная база: `books/self-education-book-create-plan.md` (План) + §2–§6 в `books/c-and-rust-book/C-and-Rust-learning.md`. Жёсткие правила (§2), кратко:

1. Никаких догадок — каждое утверждение подтверждено источниками из `sources.md`; неподтверждённое → «Открытые вопросы» в `outline.md`.
2. ≥2 независимых источника на часть; арбитры: C5 (стандарт C, N3220) для тома I, R7 (Rust Reference) для тома II.
3. Весь код прогоняется: C — MinGW GCC эталон, для глав ≥7 дополнительно ASan в WSL; Rust — `cargo build && cargo test`. Некомпилирующееся — только как помеченные ⛔-примеры.
4. Глава N ссылается только на главы 1…N−1 (проверка «забеганий вперёд» обязательна).
5. Решения — только в `solutions/`, в главах лишь условия.
6. Копирование текста источников запрещено — пересказ/синтез со ссылкой.
7. **Расхождение «текст главы ↔ прогон» — блокер захода** (владелец, 2026-08-02): чинится на месте — глава + условие в решениях + перепрогон + сверка, а не откладывается на этап 6. Перед правкой главы расхождение подтверждается повторным прогоном на свежих артефактах: половина «расхождений» — ошибка стенда (устаревший одноимённый бинарник в общем `CARGO_TARGET_DIR`, заход 26).
8. Новый источник — сначала в `sources.md`, потом в текст.

Шаблон главы — §3 (6 обязательных элементов на параграф, кроме проектных чекпоинтов глав 25, 26 и части 12.2 и параграфов-сквозных примеров вроде §18.2.3 — уточнение 2026-08-03; у последнего параграфа части свой блок «Источники» не обязателен: их даёт блок «Источники части», который идёт следом; 6–15 заданий на часть, сложность ~30/40/30). ID заданий: `ГN.ЧM.Зk`. Один заход = одна глава (или один файл решений), строго по порядку трекера §7; после захода — остановка (не терять качество на длинном контексте).
