**Технические факты главы 1 (детали — журнал 10):**

- **Первый кадр, пустая сцена 640×360, плотность 1:** вызовов 0, треугольников 0, `render.frame` 1, геометрий 0, текстур 0, программ 0, центральный пиксель `[16,24,32,255]` при фоне `0x101820` (sRGB туда-обратно точно). **С одним кубом:** 1 / 12 / 1 / 1, пиксель `[255,128,64,255]`.
- **Арбитраж по исходнику 0.185.1:** `setSize` → `canvas.width = Math.floor(width * _pixelRatio)`; `info.render.frame++` и `info.reset()` — **внутри** `render()` до отрисовки, поэтому `calls`/`triangles` описывают последний кадр, а `frame` копит вызовы; `WebGLInfo.reset()` не трогает `frame`.
- **COOP/COEP измерены:** свой сервер → `crossOriginIsolated === true`, сервер без заголовков → `false`.
- **Детерминированность:** два прогона — снимок 1456 байт, SHA-256 `8741646730365f7c`; плотность 2 — 4259 байт (другой файл, и это правильно).
- **`node --test` с каталогом не работает**: `node --test tests` → `Error: Cannot find module '…\tests'`, воспроизведено в Git Bash и PowerShell. Работают: голый `node --test`, `node --test "tests/*.test.mjs"`, явный файл. Шаблоны по умолчанию включают и `.ts`, если нет `--no-strip-types`.
- **Ловушки слоя 2, обе стоили прогона:** `gl.readPixels()` даёт предупреждение драйвера `GPU stall due to ReadPixels` (в тексте предупреждения изменчивый id контекста — сверять только подстрокой), поэтому в стенде разведены ошибки (роняют) и предупреждения (список ожидаемых); закрытие браузера и сервера обязано быть в `finally`, иначе упавший ассерт вешает `node --test` (наблюдалось 130 с до остановки), а отчёт писать на диск **до** ассертов.
- **TypeScript 7.0.2:** файлы в командной строке при наличии `tsconfig.json` → **TS5112**, лечится `--ignoreConfig`. Запрет нестираемого синтаксиса: `const enum`, параметр-свойство, `namespace` с содержимым → **TS1294** у компилятора и `SyntaxError [ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX]: TypeScript <конструкция> is not supported in strip-only mode` у Node; **декоратор компилятор пропускает молча**, Node даёт безликое `SyntaxError: Invalid or unexpected token`. Отсюда правило двух проверок.
- Сборка esbuild: `web/bundle.js` 1.0 МБ + карта 2.7 МБ за ~95 мс. Прогон обоих слоёв `npm test` ≈ 1,1 с (браузерный сценарий ≈ 0,8 с).
