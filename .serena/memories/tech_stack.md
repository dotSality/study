# Tech stack

Контент — Markdown (русский). Код книг — C и Rust; верификация двумя контурами:

- **Windows (эталон для C)**: GCC 15.2.0 MinGW-w64 (scoop), `-std=c17 -Wall -Wextra`. LLP64: `int`=4, `long`=4, `long long`=8. ASan/UBSan под MinGW **не линкуются** (libasan/libubsan нет); работает только `-fsanitize=undefined -fsanitize-trap=undefined` (крах без отчёта).
- **WSL1 Ubuntu-24.04** (WSL2 недоступен — виртуализация выключена в BIOS): gcc 13.3.0, clang 18.1.3, valgrind 3.22.0, make 4.3, rustc 1.75 (apt). Санитайзеры (ASan/UBSan/TSan) и valgrind — только здесь. Файлы Windows видны как `/mnt/c/...`; N3220 PDF лежит в `/root/n3220.pdf`.
- **Контур M (Mac M3) — только для asm-книги** (решение владельца 2026-07-30: Rust-заходы ведутся на винде, rustup на мак не ставится). Состав сверен прямым прогоном 2026-07-31 (протокол — `books/asm-book/asm-book-requirements.md` §7.2, вторая запись): macOS 15.7.4 сборка 24G517, Darwin 24.6.0, хост arm64; Apple clang 17.0.0 (clang-1700.0.13.5), CLT в `/Library/Developer/CommandLineTools`, компоновщик `ld-1167.5`, `objdump` — Apple LLVM 17, python3 3.14.6 (homebrew), Rosetta 2 работает. Сборка x86-64 — `clang -arch x86_64` (результат: «Mach-O 64-bit executable x86_64»). **`lldb` есть, `gdb` отсутствует** — предпосылка FR-6 подтверждена. **`as` на маке — не GNU as, а обёртка над `clang -cc1as`**: принимает директивы GNU as, кроме `.section .rodata` (маковские формы — `.const`, `.cstring`, `.section __TEXT,__cstring`), а `.align` толкует как степень двойки. В журнал §10 C-книги данные ещё не перенесены (открытый вопрос В2).
- **Контур L глазами asm-книги** (снимок 2026-07-30, тот же WSL1 Ubuntu 24.04): gcc 13.3.0, clang 18.1.3, GNU as (binutils) 2.42, `objdump` — binutils, `gdb` есть, **`lldb` отсутствует** — а FR-6 назначает его основным отладчиком, к главе 7 понадобится `apt install lldb`; python3 3.12.3, coreutils `stty` 9.4. Важное поведение: **pty в WSL1 игнорирует `VMIN`/`VTIME`**, поэтому неблокирующее чтение клавиши делается через `poll(2)`, а не через `stty min 0 time 1` (протокол прогона — §7.2 требований).
- **GNU Make 4.4.1** на Windows (scoop, ezwinports) — работает из Git Bash.
- Node.js — verify-скрипты линалгебра-книги.
- Rust на Windows (эталон для тома II, установлен 2026-07-11): **rustup, rustc/cargo 1.97.0 stable, host `x86_64-pc-windows-gnu`** (MSVC Build Tools на машине нет; gnu-тулчейн самодостаточен). `~/.cargo/bin` в PATH новых терминалов; в сессиях агента добавлять `$env:Path = "$env:USERPROFILE\.cargo\bin;$env:Path"`. rustc 1.75 (apt, WSL) — запасной контур.

- **poppler 26.02.0** на Windows (scoop, установлен 2026-07-28): `pdftoppm` — обязателен для чтения PDF инструментом Read, без него PDF не открываются вовсе; `pdftotext`/`pdfinfo` — дешёвая навигация по книге (найти раздел, подтвердить издание по копирайту) до чтения страниц. Нужен для закрытых изданий книги о движке (`books/three-based-custom-engine/extra-sources/`, в git не попадает) и для `/root/n3220.pdf`.

Детали и история настройки — журнал §10 в `books/c-and-rust-book/C-and-Rust-learning.md`; по книге о движке — раздел 10 в `custom-three-based-engine-book.md`.
