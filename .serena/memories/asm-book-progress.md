**Приёмы стендов.** Маковский (сверочный скрипт, `lldb` батчем, pty, `as -arch x86_64`, `objdump -s -j __data`, `dyld_info -fixups`) — в git-истории записи 2026-08-05. На виндовой машине: **heredoc через `wsl -e bash -lc` ломается** — листинги писать файлами в scratchpad и копировать в WSL через `/mnt/c/...`; иначе файлы молча падают в текущий каталог инструмента (в этот раз — прямо в `books/asm-book/chapters/`, поймано `git status`). Пользователь WSL — `max`, не root, стенд в `$HOME`. `pdftotext` — `/mingw64/bin/pdftotext`, копии S2 в `books/asm-book/extra-sources/`.

**Осторожно с коммитами:** владелец параллельно ведёт сессии по другим книгам в одном рабочем дереве. Коммитить только формой `git commit <явные пути> -m …`; новый файл сначала `git add <путь>`; после коммита `git status --porcelain` обязан быть пустым — Serena-памяти в `.serena/memories/` отслеживаются и идут **тем же** коммитом (`mem:task_completion` пп. 6, 6a, 6f).
