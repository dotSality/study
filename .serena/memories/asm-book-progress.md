# asm-book-progress

Самоучитель по ассемблеру x86-64 (`books/asm-book/`) — третья книга репо, ведётся по общему Плану. Источник истины — файлы книги, эта память только указатель.

Состояние на 2026-07-30 (заход «этап 1» завершён):

- **Этап 0 закрыт**: `asm-book-requirements.md` — решения владельца Р1–Р6 (x86-64 System V ABI, AT&T как основной синтаксис, отдельная самодостаточная книга, два итоговых проекта: VM байт-кода + змейка, черновой охват 9 глав, ввод-вывод только через libc — NFR-1), двухконтурная верификация L (WSL1 Ubuntu 24.04) / M (Mac M3 + Rosetta 2), журнал прогонов §7.2.
- **Этап 1 закрыт 2026-07-30**: `books/asm-book/sources.md` — 23 источника (A1–A5 учебники и курсы, S1–S8 спецификации, T1–T10 инструменты), матрица покрытия глав в §4 реестра, оговорки в §6. Итоги продублированы в §5.1 требований.
- **Следующая клетка: этап 2 — `outline.md`** (программа курса), утверждается владельцем до написания первой главы. Потом — `Asm-learning.md` (операционный документ + трекер, FR-7), затем этап 3 с главы 1.

Что важно помнить из этапа 1 (детали — в `sources.md` §6):

- **Intel SDM недоступен из агентской среды** (403 на канонической странице, `intel.com`/`developer.apple.com`/`learn.microsoft.com` не пускают сетевой слой агента, но веб-загрузчик их читает). Арбитр по семантике инструкций — **AMD64 APM** (тома 1 и 3, docs.amd.com, ревизии 2025 г.). Арбитр по ABI — **psABI 1.0 от 12.03.2025**, по терминалу — **POSIX.1-2024**, по управляющим последовательностям — **ECMA-48**, по синтаксису/директивам — руководство **GNU as** (binutils 2.47).
- **Пробел по Mach-O подтвердился**: `.section __TEXT,__text` описан только в архивной «OS X Assembler Reference» (PowerPC/i386, помечена Apple как не обновляемая). Раздел пишется по документации Apple + собственному прогону на контуре M, с оговоркой в тексте.
- **Плантц (No Starch, 2022) пишет в Intel-синтаксисе** (`.intel_syntax noprefix` поверх GNU as) — как образец листингов не годится, но закрывает параграф о втором диалекте (NFR-3).
- CS:APP3e и Dive into Systems подтверждены как две независимые опоры на каждую ассемблерную тему; слайды CMU 15-213 скачиваются без логина и написаны в AT&T.
- Скриптовая проверка ссылок реестра: 42 из 48 отдают 200; шесть «ERR» — ограничение среды, ссылки живые (в реестре это оговорено, удалять их нельзя).

Блокировки: **В10** (механизм ввода змейки `poll(2)` подтверждён только на контуре L) закрывается прогоном на маке — §7.1 п. 3 требований; блокирует только часть 2 главы 8. `lldb` в WSL не установлен — понадобится `apt install lldb` к главе 7.

Конвенции книг — `mem:conventions`, окружение — `mem:tech_stack`, завершение захода — `mem:task_completion`, соседняя книга — `mem:c-rust-book-progress`.
