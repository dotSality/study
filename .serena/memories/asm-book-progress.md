**Что построено в 8.Ч1 (пригодится в 8.Ч2 и в решениях).** Виртуальная машина **AVM1**: заголовок файла 12 байт (магия `AVM1`, точка входа, длина кода), 18 опкодов подряд 0…17, стек операндов 256×8 и стек кадров 64×40 — оба в куче, кадр = адрес возврата + 4 слота. Четыре собираемые программы: `load.s` (137), `opstack.s` (129), `loop3.s` (148, цепочка сравнений), `vm.s` (597, 365 инструкций, таблица переходов). Состояние ВМ живёт в `%rbx`, `%r12`–`%r15` — потому что `printf` портит caller-saved. Демо-байткоды собираются командами `printf '\xNN'` прямо из книги (проверено побайтово `cmp`; `xxd` не используется — на M не проверялся).

**Приёмы, подтверждённые этим заходом:**

1. **Сверочный скрипт обязан выполнять блоки прогона по одному, в порядке документа, в одном каталоге.** Все пять дыр воспроизводимости захода — про порядок (прогон ссылался на файл, который книга учит собирать позже). Материализация всех листингов в пустой каталог (приём захода 9) этого не ловит по построению. Скрипт захода: `check.py` — извлекает ```asm-блоки, привязывает к имени файла по ближайшему `имя.s` выше, полным считает блок с `.globl`+`main:`, затем гоняет `$ `-команды с дословной сверкой; `echo $?` обрабатывается отдельно, `==NN==` нормализуется, `objdump -d` сверяется как фрагмент.
2. **Правило «имя файла до листинга» нарушено второй раз подряд** — и снова в самом большом листинге. Проверять скриптом, а не помнить.

**Приёмы стендов.** Виндовая машина: WSL-пользователь **`max`, не root** — стенд в `~/asm8c1`, `/root` недоступен; **heredoc через `wsl -e bash -lc` ломается** — писать `.py`/`.sh` в scratchpad и копировать через `/mnt/c/...`, затем `sed -i 's/\r$//'`; **`set -e` в проверочных однострочниках обрывает прогон на первой же программе, которая по замыслу возвращает ненулевой код** — не ставить; **не запускать без ограничения программу, которая может зациклиться с выводом** (опыт с испорченным счётчиком ВМ съел 5 ГБ вывода). Сессии `gdb` — в pty питоновским драйвером (`ptygdb.py`: `pty.fork`, команды по одной с паузой ~0,9 с, фильтр escape-последовательностей; `~/.gdbinit` со `set debuginfod enabled off` и `set pagination off`). Мак (контур M): сборка `clang -arch x86_64`, сообщения ассемблера через `as -arch x86_64`, сессии `lldb` — тоже питоновским драйвером через `pty.fork`; **оболочка на маке — zsh, и она не делит слова при подстановке переменной**; `readelf`/`timeout`/`pdftotext` отсутствуют, BSD `awk` не знает `strtonum`, BSD `/usr/bin/time` не знает `-f`, `leaks(1)` под Rosetta думает около минуты.
