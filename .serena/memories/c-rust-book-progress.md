- **Полезные факты гл. 22 (журнал §10, запись 2026-07-30 (3)):** **`Deref` не отвечает за печать** — обёртка с одним лишь `Deref` даёт **E0277** «doesn't implement `std::fmt::Display`»; `Box` печатается без звёздочки благодаря `impl Display for Box<T>` (R9), а `Deref` отвечает за точку и аргументы вызовов (формулировка §22.1.1 смешивает механизмы — открытый пункт). **Цена dyn видна в LLVM-IR** (`rustc -O --emit=llvm-ir`): мономорфизированная `via_generic` — `fmul, fmul, ret` (тело встроено), `via_dyn` берёт два параметра (данные + адрес из vtable) и делает `tail call ... %s.1.24.val`; **если конкретный тип за `&dyn` известен на месте вызова, LLVM девиртуализует и функция из IR исчезает** — тип надо выбирать на бегу (`env::args().count()`). Размеры: `Box<dyn Trait>`/`&dyn Trait` — 16 байт, `Box<T>`/`&T` — 8, `Option<Box<T>>` — 8 (niche), `String` — 24. `deref -> T` вместо `-> &T` даёт **две** ошибки: E0053 (подпись) + E0507 (вынос из-за `&self`). Паники `RefCell`: «already borrowed» (второй писатель / писатель при читателе) и «already mutably borrowed» (читатель при писателе); отчёт указывает на **второй** пропуск, а долгоживущий первый может остаться в другой функции. **`Weak::strong_count`/`weak_count` дают наблюдать счётчики после смерти всех сильных ручек** — так собрана таблица утечки в 5 точках. Присваивание полю за `Rc` — **E0594**. `Vec<dyn Trait>` — четыре ошибки (три E0277 про `Sized` + E0599).
