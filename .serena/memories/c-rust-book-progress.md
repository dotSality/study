## Приёмы, добытые в этом заходе

- **Локальная копия R9 вместо веба**: `~/.rustup/toolchains/stable-…/share/doc/rust/html/std/**` — там же указаны версии стабилизации (`impl<T: Send> Sync for Sender<T>` помечен «1.72.0», у `Receiver<T>` — `impl<T> !Sync`). Быстрее и точнее веб-запроса.
- **WSL — только через инструмент PowerShell** (`wsl -d Ubuntu-24.04 -u root bash -c '...'`); сценарии переносить с `tr -d '\r'`, иначе bash спотыкается о CRLF.
- `rustc`/`cargo` не видны инструменту Bash: `export PATH="/c/Users/Max/.cargo/bin:$PATH"`.
- **Правило «сначала перепрогон, потом правка» окупилось второй раз подряд**: один из десяти пунктов оказался не расхождением главы, а неверной записью в списке долга.
- Правки CRLF-файлов инструментом Edit переводят файл целиком в LF; для операционного файла нормализация обратно node-скриптом обязательна (в индексе всё равно LF — `.gitattributes`).
