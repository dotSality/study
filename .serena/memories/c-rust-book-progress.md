## Приёмы и грабли захода (важно для сверочных скриптов)

- **Заголовок раздела решений без ID ломает разбор по ID.** `### Разминка (задание без номера)` в `solutions/14-rust-start.md` утаскивала своё условие в предыдущее задание, если раздел обрывается только по списку жирных меток (`**Решение.**`, …). Единственное «расхождение» первого прогона оказалось артефактом парсера. Правило: раздел закрывается **любым** заголовком `###`, разделы без ID считать и печатать отдельно.
- **Номера параграфов курса сталкиваются с номерами стандарта C**: `C5 (§6.2.1, 6.2.4)` в главе 4 «разрешается» в существующий §6.2.1 курса и выглядит как забегание вперёд. Автоматика даёт кандидатов, а не приговор — все просматривать глазами.
- **Порядок классификации ссылок:** сначала пробовать разрешить в курсе, и только неразрешённое проверять на ссылку в источник. Контекстный поиск ID источника первым фильтром ошибается в обе стороны.
- Выборочный перепрогон брал главы, которых не касалась выборка сквозной ревизии (та — C 2–11, Rust 14–23): шесть листингов из глав 12, 13, 24, 25 собраны и запущены заново, выводы совпали с текстом дословно.
